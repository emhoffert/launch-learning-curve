Launch Learning Curve Simulator

About the model (Wright's Law)

Wright's Law: each time cumulative launches double, the modeled cost per launch falls by the learning rate. cost(n) = C₁ × nb, where b = log₂(1 − learning rate).

Modeled learning subsidy

Modeled learning subsidy assumes someone funds the difference between the modeled launch cost and the target launch cost for each launch, from launch 1 until the target is reached: the sum of max(modeled cost − target cost, 0) over those launches. It is not an estimate of an economically optimal subsidy.

Probability of reaching the target

Bands show 10,000 simulated learning rates. Dates use the expected rate.

Details

Probabilities are conditional on the assumed probability model, not forecasts of real launch costs. 10,000 simulations each draw one learning rate from a normal distribution centered on the expected learning rate (1σ = the uncertainty in percentage points) and truncated to the valid 0%–100% range (0% ≤ LR < 100%), and use it for the whole curve. Draws outside that range are redrawn, never clamped. Negative learning, where costs would rise with experience, is excluded in this version. A fixed random seed makes the results reproducible. Because the distribution is symmetric, the median closely tracks the single-learning-rate curve. All other readouts use the single learning rate above.
