Launch Learning Curve Simulator

Wright's Law: each time cumulative launches double, the modeled cost per launch falls by the learning rate. cost(n) = C₁ × nb, where b = log₂(1 − learning rate).

Dots mark each doubling of cumulative launches (1, 2, 4, 8, …). The right axis shows the same cost per kilogram, assuming an illustrative Starship payload of 100 t (100,000 kg) per launch.
